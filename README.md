# 🕹️ Prompt Playground

> An interactive sandbox environment for testing, iterating, and optimizing LLM prompts, parameters, and system instructions in real time.

---

## ✨ Features

* **Real-Time Experimentation:** Tweak system prompts, user inputs, and template variables on the fly.
* **Parameter Tuning:** Dial in exact controls for temperature, top-p, context windows, and output lengths.
* **Model Agnostic / Local Ready:** Easily configure endpoints to point to cloud providers or local runners (like Ollama).
* **Lightweight & Fast:** Built for developers who want a quick, distraction-free environment to validate prompt logic before pushing it into production code.

---
